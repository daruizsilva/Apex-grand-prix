# Apex Grand Prix

A 3D Formula-style racing game that runs in the browser and installs on iPhone as a full-screen home-screen app.

**Play:** https://daruizsilva.github.io/apex-grand-prix/

## Install on iPhone

1. Open the link above in **Safari**.
2. Tap the **Share** button, then **Add to Home Screen**.
3. Open **Apex GP** from your home screen and hold the phone sideways.

## Features

- Six real circuits built from GPS surveys: Monza, Silverstone, Spa-Francorchamps, Interlagos, Red Bull Ring and Monaco, with elevation
- Race weekends: qualifying, grid flyover, five-light start, race and podium ceremony
- Championship (six rounds, points and standings), Quick Race and Time Trial
- Garage: livery, car number and three-letter driver code
- Records, settings (driving assist, auto-throttle, steering, camera, graphics, units, sound) and saved progress
- Touch controls for iPhone, keyboard controls on desktop, works offline after the first visit
